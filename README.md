# Ermita del Silencio

Página web (Next.js) de la Ermita del Silencio.

## Desarrollo local

```bash
npm ci
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

Variables de entorno: copia [`.env.example`](./.env.example) a `.env.local` y ajusta valores.

## Despliegue en Vercel

Instrucciones, variables de entorno y limitaciones del almacenamiento en servidor: **[VERCEL.md](./VERCEL.md)**.

Configuración del proyecto: [`vercel.json`](./vercel.json).
